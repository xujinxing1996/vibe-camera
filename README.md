# vibe-camera(非古法编程)
使用方法：
按照uni-app官网原生插件使用方法测试：https://nativesupport.dcloud.net.cn/NativePlugin/course/android.html
dcloud_uniplugin.json: 
{
    "plugins": [
      {
        "type": "component",
        "name": "vibe-camera",
        "class": "com.psi.uniplugin_vibe_camera.UniCameraView"
      }
    ]
},
